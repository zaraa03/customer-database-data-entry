# Customer Database Data Entry & Cleaning

## Project Overview
This project focuses on data entry and data cleaning using Microsoft Excel.

The raw customer data contained several data quality issues, including inconsistent formatting, duplicate records, inconsistent city names, and different date formats.

## Tasks Performed
- Entered customer data into Microsoft Excel
- Identified and removed duplicate records
- Standardized customer names
- Standardized city names
- Standardized registration date formats
- Checked for missing email addresses
- Checked for missing phone numbers
- Added customer status data
